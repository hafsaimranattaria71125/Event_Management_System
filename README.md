# Event Management System — Database Systems Project

---

A relational database for managing events — scheduling, ticketing, vendors, sponsors, and feedback. Built in Oracle SQL, normalized to 3NF.

## How to Run

Execute `event_management_system.sql` in Oracle SQL Developer or SQL*Plus. Tables must be created before views and reports are run.
